# Versafy — ИИ-ассистент по продажам

Файлы с кодом, которыми пользуется ИИ-ассистент Versafy. Правила его работы описаны в Google Doc «Versafy — регламент ИИ-ассистента»; здесь хранится только то, что имеет программную природу.

## Содержимое

| Путь | Что это |
|---|---|
| `templates/change-card.html` | Эталон интерактивной карточки изменений (регламент, раздел 3). Инструкция по использованию — HTML-комментарий в начале файла. |

## Как вносятся изменения

1. Изменение готовится в отдельной ветке.
2. Открывается pull request с описанием: что меняется и зачем. Для изменений вёрстки прикладываются изображения карточки «до» и «после».
3. Владелец репозитория просматривает изменения, при необходимости комментирует строки и одобряет pull request слиянием в `main`.

Действующей считается версия в ветке `main`. Прямые изменения в `main` не вносятся.
